# 🩺 Medical Reminder Website

A web application designed to help patients and caregivers manage medication schedules, appointments, and health reminders with ease and reliability.

---

## 🚀 Features
- User-friendly dashboard for managing reminders
- Add, edit, and delete medical reminders
- Notifications for upcoming medications or appointments
- Secure login and patient profile management
- Responsive design for desktop and mobile
